# mikrio-cli

Command-line interface for mikrio object storage.

The executable is `mikrio`. Install the platform archive from
[GitHub Releases](https://github.com/meltyshev/mikrio/releases) and keep its
matching SQLite companion. `cargo install` does not deploy that companion. Run
`mikrio --help` for commands.

See the [project documentation](https://github.com/meltyshev/mikrio) for
building, deployment, compatibility, and the required shared SQLite runtime.
