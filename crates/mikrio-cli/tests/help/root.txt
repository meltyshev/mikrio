Local S3 storage and trusted directory administration

Usage: mikrio [OPTIONS] <COMMAND>

Commands:
  init        Initialize or reopen storage and ensure buckets exist
  serve       Serve a foreground S3 listener until shutdown
  principal   Administer persistent application identities in an existing store
  access-key  Create, inventory and revoke persistent application credentials
  policy      Replace, read or delete one bucket or identity policy locally
  help        Print this message or the help of the given subcommand(s)

Options:
      --json     Emit schema 1 JSON results and diagnostics
  -h, --help     Print help
  -V, --version  Print version

All commands require a positional store directory after the complete command path. Administration requires an existing store. Directory access is trusted authority; no HTTP administration or AWS profile discovery. Use -- before a leading-hyphen directory. Exit codes: 0 success, 2 invalid input/configuration, 1 storage/runtime/I/O failure. JSON result output precedes close; also check the exit status.
