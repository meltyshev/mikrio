Delete a policy; an absent policy on an existing target succeeds

Usage: mikrio policy delete [OPTIONS] <--bucket <NAME>|--principal-id <ID>> <DIR>

Arguments:
  <DIR>  Managed store directory

Options:
      --bucket <NAME>      Bucket policy target
      --json               Emit schema 1 JSON results and diagnostics
      --principal-id <ID>  Identity policy target
  -h, --help               Print help
