Create, inventory and revoke persistent application credentials

Usage: mikrio access-key [OPTIONS] <COMMAND>

Commands:
  create  Create a key and disclose its secret once
  list    Read one key page without secrets
  revoke  Revoke only the named principal's key
  help    Print this message or the help of the given subcommand(s)

Options:
      --json  Emit schema 1 JSON results and diagnostics
  -h, --help  Print help
