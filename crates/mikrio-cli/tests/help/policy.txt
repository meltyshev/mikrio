Replace, read or delete one bucket or identity policy locally

Usage: mikrio policy [OPTIONS] <COMMAND>

Commands:
  apply   Atomically replace one complete policy
  get     Read the exact stored policy document
  delete  Delete a policy; an absent policy on an existing target succeeds
  help    Print this message or the help of the given subcommand(s)

Options:
      --json  Emit schema 1 JSON results and diagnostics
  -h, --help  Print help
