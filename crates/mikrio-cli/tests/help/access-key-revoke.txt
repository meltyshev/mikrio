Revoke only the named principal's key

Usage: mikrio access-key revoke [OPTIONS] --principal-id <ID> --access-key-id <ID> <DIR>

Arguments:
  <DIR>  Managed store directory

Options:
      --json                Emit schema 1 JSON results and diagnostics
      --principal-id <ID>   Stable principal ID, not a name or ARN
      --access-key-id <ID>  Persistent access key ID
  -h, --help                Print help
