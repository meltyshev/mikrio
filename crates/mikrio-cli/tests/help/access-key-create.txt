Create a key and disclose its secret once

Usage: mikrio access-key create [OPTIONS] --principal-id <ID> <DIR>

Arguments:
  <DIR>  Managed store directory

Options:
      --json               Emit schema 1 JSON results and diagnostics
      --principal-id <ID>  Stable principal ID, not a name or ARN
  -h, --help               Print help

Store this command's sensitive result securely. Rotation: create and test a second key, then explicitly revoke the old key. Inventory cannot recover a lost secret.
