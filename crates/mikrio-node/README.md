# mikrio-node

Native Node.js binding for mikrio.

This crate is an implementation detail of mikrio. Application code should use
the public [`@mikrio/node`](https://www.npmjs.com/package/@mikrio/node) package.

See the [project documentation](https://github.com/meltyshev/mikrio) for
building, deployment, compatibility, and the required shared SQLite runtime.
